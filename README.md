# Detector de Almas en Pena

App de broma de terror para jugar con amigos: tablero de espiritismo, radar de presencias,
llamada fantasma y cámara espectral. PWA de un solo `index.html`, sin build y sin backend;
funciona sin conexión una vez abierta.

- **Usar:** https://detector-almas.vercel.app (en el teléfono: «Agregar a pantalla de inicio»).
- **Descargar:** botón *Code → Download ZIP* de este repo; se abre sirviendo la carpeta
  con cualquier servidor estático (`npx serve .`). La cámara necesita https o localhost.
- **Trucos:** mantén apretado el ☼ del tablero 2 segundos para abrir el panel del médium.

La voz (`voz/mespeak.js`) es meSpeak/eSpeak, licencia GPL-3.0 (ver `LICENSE-voz.txt`).
Los sonidos de `sonidos/` son grabaciones de freesound.org con licencia CC0 (ver `sonidos/CREDITOS.txt`).
